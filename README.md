# Digital_Body_Twin
Personal Health Trajectory Reconstruction and change detection - An AI driven healthcare research project that analyzes longitudinal patient data to reconstruct health timelines, learn personalized baselines, detect meaningful changes, and provide evidence-linked explanations of how a patient's health evolves over time.
An experimental AI + Data Science healthcare research project focused on understanding how an individual's health changes over time.
Instead of simply predicting whether a patient has a particular disease, the system aims to answer a different question:
"What changes in this patient's health, when did it change, and what evidence supports that change?"
CORE IDEA
Healthcare info is often scattered across laboratory reports, clinical notes, medications, symptoms and vital measurements.
This project aims to combine these longitudinal data sources into an evolving personal health trajectory.
